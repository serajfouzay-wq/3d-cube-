# 3d-cube-

Two things live here.

## `cabinet/` — Cabinet desktop application

The working project. A local Electron + React + Tailwind + SQLite desktop app
that scans a machine for documents, files them by company and document type,
and drafts new proposals from what it finds.

See **[cabinet/README.md](cabinet/README.md)**.

```bash
cd cabinet
npm install
npm start
```

## Prototypes at the root

`index.html`, `index-cube-version.html`, `index-backup.html` and
`cinmaticbackground.jsx` are earlier WebGL experiments, kept for reference.
They are unrelated to Cabinet and nothing in `cabinet/` depends on them.
